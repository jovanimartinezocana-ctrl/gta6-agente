# BITÁCORA DEL PUBLICADOR

El Agente A escribe aquí al final de cada corrida. El Agente B lo lee cada
domingo para entender no solo qué se publicó, sino **qué se descartó y por qué** —
que muchas veces es la información más útil.

## Formato de cada entrada

```
## YYYY-MM-DD
**Hallazgos:** N de prensa, N de comunidad
**Publicados:** N
**Descartados:** [tema] — [motivo: repetido / sin sustancia / poco relevante / filtración]
**Nota:** [cualquier cosa rara que valga la pena registrar]
```

Si un día no se publica nada, se registra igual con el motivo. Los días en
silencio son datos, no huecos.
